# 단위 시험 파일 관리

정의 출처: PPT 18장의 phi_cmd = 0 및 기존 MD의 UT 시험 정의. [생명주기 MD](../../docs/Software_Lifecycle.md) 8~9절을 참조한다.

2026-10-05에 testBankCommand.m을 추가했다. 기존 구현의 0 명령 및 +/-45도 제한을 확인하는 예제이며 허용 오차는 1e-10 rad이다. 프로젝트 최상위에서 tests/runBankCommandTest.m을 호출하면 판정과 데이터를 버전별 결과 폴더에 저장한다. 다른 과거 시험 코드가 복원되었다는 의미는 아니다.

향후 시험 파일에는 기존 시험 ID, 연결된 요구사항·설계 항목, 입력, 기대값, 허용 오차를 명시한다. 실행 결과는 tests 안에 덮어쓰지 않고 results/<실행_ID>/에 저장한다. MATLAB 원본은 수정하지 않는다.
