# 통합 시험 파일 관리

정의 출처: 기존 MD의 IT 시험 정의. [생명주기 MD](../../docs/Software_Lifecycle.md) 8~9절을 참조한다.

현재 시험 실행 파일은 이 폴더에 없다. 폴더 생성은 시험 구현 또는 실행 완료를 의미하지 않는다. 이번 작업에서 시험 코드나 합격 기준을 새로 작성하지 않았다.

향후 시험 파일에는 기존 시험 ID, 연결된 요구사항·설계 항목, 입력, 기대값, 허용 오차를 명시한다. 실행 결과는 tests 안에 덮어쓰지 않고 results/<실행_ID>/에 저장한다. MATLAB 원본은 수정하지 않는다.
