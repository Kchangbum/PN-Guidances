# 자동화 관리

운영 규칙은 [생명주기 MD](../docs/Software_Lifecycle.md) 12절에 있다. 이 폴더는 해당 규칙의 구현 파일을 저장할 위치다.

향후 maintain.ps1, maintenance_config.json을 이 위치에 두며, 점검·해시 비교·경로 검사·보고서 생성을 기본 범위로 한다. 유지관리 스크립트와 설정은 아직 구현하지 않았다.

2026-10-05에 runVersionedSimulation.m을 추가했다. 기존 main을 실행하고 생성된 Figure·원본 데이터·소스 사본·로그를 results/v0.2.0/<실행ID>/에 저장한다. 별도 유지관리 자동화나 유도 정확도 시험을 수행하는 함수는 아니다.

자동화는 원본 MATLAB 코드, 요구사항·설계·합격 기준을 수정하지 않는다. 삭제·Git 작업·GitHub 배포는 기본 실행에 포함하지 않는다. 이번 요청은 파일과 산출물 정리이며 자동화 프로그램 실행을 의미하지 않는다.
