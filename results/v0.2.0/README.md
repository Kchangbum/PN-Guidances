# v0.2.0 결과

v0.2.0은 개발 중 버전이다. 이 폴더에 결과가 있다는 사실이 버전 전체의 검증 완료를 뜻하지 않는다.

```text
<실행ID>/                  날짜·시각, Asia/Seoul
  report.md                실행 조건·시험 범위·실제 판정
  data/                    CSV·MAT 수치 원본 및 시험 소스 사본
  figures/                 해당 실행에서 생성한 Figure
  logs/                    실행 로그가 있는 경우 저장
```

[뱅크각 시험 실행 함수](../../tests/runBankCommandTest.m)는 실제 실행 시 새 폴더와 보고서를 만든다. 이 시험은 Figure를 생성하지 않으므로 figures/는 비어 있을 수 있다. [시뮬레이션 저장 함수](../../automation/runVersionedSimulation.m)는 기존 main의 Figure와 데이터를 별도 실행 폴더에 저장한다.

기존 Figure는 [legacy 기록](../legacy_2026-10-02/report.md)에서 확인한다. 이전 결과를 새 버전의 시험 증거로 재분류하지 않는다.

## 2026-10-05 실행 결과

| 환경 | 뱅크각 시험 | 시뮬레이션·Figure |
|---|---|---|
| R2025b Update 4 (대표 결과) | [3개 통과](2026-10-05_005327_073/report.md) | [6개 Figure](2026-10-05_005331_297/report.md) |
| R2024a Update 8 | [3개 통과](2026-10-05_005300_017/report.md) | [6개 Figure](2026-10-05_005303_716/report.md) |

위 두 실행의 표적 속력은 0 m/s, APN 보상 가속도는 0이므로 PPN과 APN이 같은 결과를 낸다. 기존 알고리즘·시각화 코드를 그대로 실행했다. 궤적 범례에 시작·종료 항목이 모두 표시되는 상태도 원본대로 보존했다.

### 기동 표적 추가 실행

[2026-10-05_005619_729 결과](2026-10-05_005619_729/report.md): R2025b Update 4, 표적 속력 80 m/s, 표적 횡가속도 +1 m/s², APN 보상 입력 +1 m/s². PNG·FIG 각 6개와 원본 데이터를 저장했다. 이전 정지 표적 결과는 보존했다. 현 작업 코드도 이 조건으로 변경했다. 이 실행에서 뱅크각 시험은 다시 실행하지 않았으며 유도 정확도 합격 판정도 하지 않았다.

뱅크각 단위 시험 통과와 유도 알고리즘 전체의 정확도 검증을 구분한다. 종료 전 표본을 반환하는 기존 처리와 마지막 표본 문제는 이번 저장 작업에서 수정하지 않았다.

다시 시뮬레이션 결과를 저장하려면 프로젝트 최상위에서 실행한다.

```matlab
addpath('automation');
outputDirectory = runVersionedSimulation();
```
