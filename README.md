# PN-Guidances

MATLAB 기반 2차원 비례항법(PN) 시뮬레이션과 소프트웨어 개발 생명주기 문서를 정리한 학습 프로젝트입니다. 현재 구현은 PPN(Pure Proportional Navigation)을 사용하며, 운동 궤적과 상대기하, 명령 이력을 그래프로 확인합니다.

## 실행 환경과 방법

MATLAB R2025b Update 4에서 실행을 확인했습니다. 기본 실행은 MATLAB의 `ode45`와 그래프 기능을 사용합니다.

1. 저장소를 다운로드하거나 복제합니다.
2. MATLAB의 현재 폴더를 저장소 폴더로 지정합니다.
3. 명령 창에서 다음을 실행합니다.

```matlab
main
```

`main.m`은 실행 시 작업 공간을 초기화하고 열려 있는 Figure 창을 닫습니다. 필요한 작업은 실행 전에 저장하세요.

`guidance.m`은 기본 시뮬레이션과 별도로 실행하는 일정 뱅크각 및 바람 조건 예제입니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `main.m` | 초기화, 시뮬레이션 실행, 이력 저장, 시각화 호출 |
| `configuration.m` | 시간, 초기 상태, 속력, 바람 등 설정 |
| `computeRelativeGeometry.m` | 상대거리, 거리 변화율, LOS 각도와 각속도 계산 |
| `computePNGuidance.m` | 현재 PPN 가속도 명령 계산 |
| `computeBankCommand.m` | 가속도 명령을 뱅크각 명령으로 변환 |
| `computeKinematics.m` | 위치와 기수각의 운동학 계산 |
| `visualizeSimulation.m` | 결과 그래프 표시 |
| `guidance.m` | 별도 운동학 예제 |
| `Software_Lifecycle.md` | 요구사항, 설계, 변수·명명 규칙, 검증 및 합격 기준 정리 |
| `Guidance_Software_Framework.pptx` / `.pdf` | 소프트웨어 개발 프레임워크 자료 |
| `Classical_PN_Guidance_2D_Derivation_final.pptx` | PN 유도 관련 정리 자료 |
| `전체적인 내용 시스템 알기.txt` | 학습 메모 |

## 출력 결과

기본 실행은 다음 6개 Figure를 표시합니다.

- XY 궤적
- 기수각
- 상대거리와 거리 변화율
- LOS 각도와 각속도
- 뱅크각 명령
- 횡가속도 명령

PNG 자동 저장 기능은 기본 실행에 포함되어 있지 않습니다.

## 개발 및 검증 상태

현재는 기본 구현 후 단위·통합·시스템 검증을 진행하는 단계입니다. 실행 및 기본 계산 확인과 전체 요구사항의 최종 합격 판정은 구분합니다.

별도 로컬 검증 기록은 24개 항목 중 21개 통과, 3개 실패입니다. 해당 결과는 당시 시험 조건에 한정되며, 시험 실행 파일과 PNG·데이터 산출물은 이 저장소에 포함되어 있지 않습니다. 자세한 조건과 기록은 [Software_Lifecycle.md](Software_Lifecycle.md)를 참고하세요.

확인하거나 정리해야 할 사항은 다음과 같습니다.

- 상대거리 0에서 LOS 방향과 각속도 계산의 정의 범위
- 시간 제한 종료 시 마지막 상태와 일부 이력의 시점 일치
- 정지 표적과 바람 조건에서 상대기하와 운동학의 속도 정의 일치
- 접근 구간의 마지막 샘플과 실제 최근접점의 구분

최근접점 통과 이후에는 LOS 방향이 급격히 바뀔 수 있습니다. 이 현상만으로 각속도 발산이나 성공 여부를 판단하지 않습니다. 최소 샘플 거리, 종료 조건, 별도로 정한 합격 기준을 함께 확인해야 합니다.
