# v0.2.0 — Step 2. 시스템 설계：결과 데이터 표시 범위

작성일: 2026-10-02 (Asia/Seoul)

상태: **결과 표시 부분의 시스템 설계 초안 작성, 사용자 검토 전**.

기준: [1단계 변경 요구사항](01_requirements.md), [기존 시각화 파일](../../visualizeSimulation.m), [원본 PPT](../Guidance_Software_Framework.pptx)의 Step 2 시스템 기능 구성 방식.

## 1. 범위

사용자의 “기존 시스템과 동일”이라는 설명에 따라 기존 입력·출력과 Figure 구성을 유지한다. 이 산출물은 이미 제공된 결과 데이터의 표시를 다루며, 세 가이던스를 실행하는 시스템 전체 설계는 아니다.

가이던스 계산, 운동 계산, 상태 갱신, 종료 판단, 성능 평가와 해당 시험 조건은 설계 범위에 포함하지 않는다. TPN·PPN·APN은 사용자 요청에 따른 결과의 식별 이름으로 기록한다. 표시 기능이 해당 알고리즘을 구현하거나 실행한다는 뜻은 아니다.

## 2. 입력·출력 정의

| 구분 | 정의 |
|---|---|
| 입력 | 기존 시스템에서 제공하는 시간과 결과 이력. 새로운 파일 입력이나 실행 기능은 추가하지 않음 |
| 식별 정보 | 표시 대상 결과를 구분하는 이름 |
| 출력 | 기존 Figure 구성에 따른 화면 표시 |
| 저장 방식 | 기존 방식 유지. 기존 시각화 파일에 없는 자동 PNG·MAT 저장 기능을 추가하지 않음 |

각 결과의 출처와 이름은 구분한다. 결과 데이터가 없으면 선을 임의로 생성하지 않고 부재를 표시한다. 기존 입력을 복제해 서로 다른 결과인 것처럼 표시하지 않는다.

## 3. 시스템 기능과 역할

아래는 논리적인 기능 분류다. 각 행을 별도 함수·클래스로 구현하라는 뜻은 아니다.

| 기능 | 역할 | 입력 | 출력 |
|---|---|---|---|
| 입력 확인 | 제공된 데이터와 식별 정보가 있는지 확인 | 기존 결과 데이터와 이름 | 표시 가능한 데이터와 부재 안내 |
| 표시 구성 | 기존 Figure 종류와 축의 의미를 유지 | 표시 가능한 데이터 | Figure 구성 |
| 결과 표시 | 동일 종류의 제공된 데이터를 같은 Figure에서 식별 가능하게 표시 | 데이터와 표시 대상 이름 | 구분되는 선과 범례 |
| 상태 안내 | 없는 데이터와 표시 실패를 숨기지 않음 | 입력·표시 상태 | 사용자 안내 |

이 기능 구성은 CHG-03의 출력 요청을 정리한 것이다. CHG-02의 가이던스 실행 환경은 이 문서로 설계 완료 처리하지 않는다.

## 4. 기존 Figure 구성 기록

현재 visualizeSimulation.m의 화면 구성은 다음과 같다. 아래 목록은 기존 코드의 출력 종류를 기록한 것이며 새로운 성능 분석 항목을 추가한 것이 아니다.

| 화면 제목 | 기존 표시 내용 |
|---|---|
| XY Trajectories | 평면 궤적과 시작·종료 표시 |
| Heading | 기수각 |
| Range | 상대거리와 거리 변화율의 두 서브플롯 |
| LOS | LOS 각도와 각속도의 두 서브플롯 |
| Bank angle command | 뱅크각 명령 |
| lateral acceleration command | 횡가속도 명령 |

사용자 요청은 각 화면에서 해당 종류의 결과를 구분해서 함께 보는 것이다. 곡선 표시 자체는 알고리즘의 정확성·성능·우열 판정이 아니다.

## 5. 표시 기능의 전체 흐름

```text
기존 시스템이 결과 데이터를 제공
              ↓
데이터와 식별 정보의 존재 확인
              ↓
기존 Figure 구성 유지
              ↓
같은 종류의 제공된 결과를 구분해서 표시
              ↓
데이터 부재·표시 실패 안내
```

새 가이던스 실행·계산 흐름은 이 도식에 포함하지 않는다.

## 6. 구조 선택과 제약

- 중복을 줄이고 공통 표시 처리를 재사용한다는 사용자 원칙을 유지한다.
- 함수·구조체·클래스 선택과 구체적인 인터페이스는 이 단계에서 확정하지 않는다.
- 기능 표의 항목 수에 맞춰 모듈을 늘리지 않는다.
- 원본 MATLAB 코드, PPT, 기존 Figure 항목과 수치 기준을 변경하지 않는다.
- 기존 입력·출력과 결과 저장 방식이 달라지는 기능은 별도 변경 요청으로 다룬다.

## 7. 단계 결과와 남은 범위

기존 결과의 입력·출력, 화면 구성, 표시 기능과 흐름을 문서화했다. 이는 결과 표시 부분의 초안이며 전체 실행 환경의 시스템 설계 완료를 의미하지 않는다. 코드 구현·실행·시험·GitHub 업로드는 수행하지 않았다.
