# Step 2. 시스템 설계 — 산출물

기준: [원본 PPT](../../Guidance_Software_Framework.pptx) 3장. 상세 연결: [생명주기 MD](../../Software_Lifecycle.md) 4절.

이 파일은 원본과 기존 MD를 연결하는 정리본이다. 새로운 요구사항·기능·계산법·수치 기준을 추가하지 않는다.

## 관리 대상

- 시스템 기능 구성
- 기능별 역할

PPT에 제시된 기능은 조건 설정, 상대운동 계산, 유도 명령 생성, 운동 계산, 시뮬레이션 수행, 결과 평가, 결과 출력이다. 기능을 추가하지 않고 원본의 역할 구분을 유지한다.

## 유지보수

변경 시 원본 PPT, 연결된 MD 절, 담당 코드와 시험의 영향 범위를 확인한다. 변경 이유와 검증 여부를 기록하고, 사용자 승인 없이 원본 PPT·MATLAB 코드·합격 기준을 수정하지 않는다. 파일이 존재하는 것만으로 단계 완료를 선언하지 않는다.
