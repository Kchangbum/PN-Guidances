# Step 3. 소프트웨어 아키텍처 설계 — 산출물

기준: [원본 PPT](../../Guidance_Software_Framework.pptx) 4~7장. 상세 연결: [생명주기 MD](../../Software_Lifecycle.md) 5절.

이 파일은 원본과 기존 MD를 연결하는 정리본이다. 새로운 요구사항·기능·계산법·수치 기준을 추가하지 않는다.

## 관리 대상

- 모듈 구성
- 데이터 구조
- 좌표계·단위 규약

원본 모듈은 Configuration, Relative Geometry, PN Guidance, Command Mapper, Kinematics, Simulation Manager, Visualization이다. 데이터 구조와 좌표계 규약은 PPT 6~7장, 현재 파일 대응은 MD 5절을 참조한다.

## 유지보수

변경 시 원본 PPT, 연결된 MD 절, 담당 코드와 시험의 영향 범위를 확인한다. 변경 이유와 검증 여부를 기록하고, 사용자 승인 없이 원본 PPT·MATLAB 코드·합격 기준을 수정하지 않는다. 파일이 존재하는 것만으로 단계 완료를 선언하지 않는다.
