# Step 5. Test – 단위 테스트 — 산출물

기준: [원본 PPT](../../Guidance_Software_Framework.pptx) 18장. 상세 연결: [생명주기 MD](../../Software_Lifecycle.md) 8~11절.

이 파일은 원본과 기존 MD를 연결하는 정리본이다. 새로운 요구사항·기능·계산법·수치 기준을 추가하지 않는다.

## 관리 대상

- PPT의 phi_cmd = 0 시험 항목
- 기존 시험 정의·기록 연결
- 확보된 PNG와 증거 부재 목록

원본 마지막 슬라이드의 번호와 단위 테스트 제목을 유지한다. 원본에 명시된 항목은 phi_cmd = 0이다. 통합·시스템·인수 분류와 합격표는 대화 및 기존 MD의 관리 분류이며 PPT에 새 단계가 존재하는 것으로 표시하지 않는다.

## 유지보수

변경 시 원본 PPT, 연결된 MD 절, 담당 코드와 시험의 영향 범위를 확인한다. 변경 이유와 검증 여부를 기록하고, 사용자 승인 없이 원본 PPT·MATLAB 코드·합격 기준을 수정하지 않는다. 파일이 존재하는 것만으로 단계 완료를 선언하지 않는다.
