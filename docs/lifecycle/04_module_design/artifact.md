# Step 4. 모듈 설계 — 산출물

기준: [원본 PPT](../../Guidance_Software_Framework.pptx) 8~16장. 상세 연결: [생명주기 MD](../../Software_Lifecycle.md) 6절.

이 파일은 원본과 기존 MD를 연결하는 정리본이다. 새로운 요구사항·기능·계산법·수치 기준을 추가하지 않는다.

## 관리 대상

- 변수·상수·구조체·함수 명명 규칙
- 모듈 입력·처리·출력
- 시뮬레이션 매니저 흐름

변수·상수·구조체·함수 정의는 PPT 8~11장, 상대기하와 매니저·명령·운동학·시각화 설계는 12~16장에 있다. 변수 정의와 명명 규칙을 이 단계 산출물에 포함한다. 세부 내용은 MD 6.1~6.10절을 참조하며 원본 계산식을 새로 변경하지 않는다.

## 유지보수

변경 시 원본 PPT, 연결된 MD 절, 담당 코드와 시험의 영향 범위를 확인한다. 변경 이유와 검증 여부를 기록하고, 사용자 승인 없이 원본 PPT·MATLAB 코드·합격 기준을 수정하지 않는다. 파일이 존재하는 것만으로 단계 완료를 선언하지 않는다.
