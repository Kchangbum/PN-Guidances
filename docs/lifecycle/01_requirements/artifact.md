# Step 1. 요구사항 분석 — 산출물

기준: [원본 PPT](../../Guidance_Software_Framework.pptx) 2장. 상세 연결: [생명주기 MD](../../Software_Lifecycle.md) 3절.

이 파일은 원본과 기존 MD를 연결하는 정리본이다. 새로운 요구사항·기능·계산법·수치 기준을 추가하지 않는다.

## 관리 대상

- 시스템 범위
- REQ-001~005

| ID | PPT의 요구사항 |
|---|---|
| REQ-001 | 시스템은 2차원 환경에서 요격자와 타겟의 운동을 모사해야 한다. |
| REQ-002 | 시스템은 요격자와 타겟의 초기조건을 설정할 수 있어야 한다. |
| REQ-003 | 시스템은 PN 유도법칙을 이용하여 요격 명령을 생성해야 한다. |
| REQ-004 | 시스템은 설정된 조건에 따라 요격 시뮬레이션을 수행해야 한다. |
| REQ-005 | 시스템은 요격 궤적과 요격 결과를 제공해야 한다. |

## 유지보수

변경 시 원본 PPT, 연결된 MD 절, 담당 코드와 시험의 영향 범위를 확인한다. 변경 이유와 검증 여부를 기록하고, 사용자 승인 없이 원본 PPT·MATLAB 코드·합격 기준을 수정하지 않는다. 파일이 존재하는 것만으로 단계 완료를 선언하지 않는다.
