# 변경 이력

## 2026-10-10 — 기록·표시 검토 문서 추가

`docs/reviews/2026-10_simulation_review.md`에 구현 구조, 사용자 제공 배열 확인 결과, 기록 시점과 마지막 표본의 검토 사항을 정리했다. `results/reviews/2026-10-10/report.md`는 기존 실행 증거와 별도의 사용자 확인 실행을 구분한다. README에 두 문서와 검증 범위를 연결했다.

MATLAB 소스, 유도식, 설정, 기존 실행 데이터는 변경하지 않았다. 신규 시험·시뮬레이션을 실행하지 않았으며 문서 링크와 Git diff를 확인했다. 작업 폴더와 업로드 소스의 해시 차이는 기록했으나 소스를 동기화하지 않았다.

## 2026-10-05 — v0.2.0 개발 중 비교 실행과 결과 보관

main의 반복문을 runSimulation으로 분리하여 TPN·PPN·APN을 독립 실행하고, 구조체 배열을 받는 시각화로 Figure 6개를 비교 표시한다. 최신 설정은 표적 속력 80 m/s, 횡가속도 +1 m/s²와 APN 보상 입력 +1 m/s²이다.

docs/v0.2.0 설계 문서 5개, 뱅크각 시험과 실행 함수, 버전별 시뮬레이션 저장 함수를 추가했다. R2024a Update 8 및 R2025b Update 4에서 뱅크각 시험 3개 통과와 정지 표적 Figure 저장을 확인했다. R2025b에서 기동 표적 Figure 6개를 추가 저장했다. 데이터·소스 사본·로그와 이전 legacy 결과를 보존했다.

APN 식과 명령 좌표 방향, 종료·마지막 표본 처리는 검토가 남아 있다. 저장된 최소 표본 거리는 연속 최근접 거리나 요격 성공 판정이 아니다. 개발 중 버전이며 배포 태그는 생성하지 않는다. 내용 차이가 확인된 유도식 PPT와 줄바꿈만 다른 Software_Lifecycle.md는 이번 동기화에서 제외했다.

## 2026-10-02 — 로컬 산출물 정리

배포 버전·Git 태그는 부여하지 않았다. 원본 Guidance_Software_Framework.pptx의 단계 순서에 맞춰 docs/lifecycle/에 단계별 산출물·현재 결과와 추적표를 생성했다. 원본 PPT·PDF·MATLAB 소스는 변경하지 않았다.

tests/의 검증 분류와 automation/ 관리 위치를 만들고 기존 output/ PNG 7개를 results/legacy_2026-10-02/png/로 이동했다. 과거 시험 판정과 현재 확보된 증거를 구분했다. 시험 실행 파일·수치 원본은 부재이며 신규 시험은 실행하지 않았다.

GitHub 업로드용 사본과 원격 저장소는 갱신하지 않았다. 배포 변경은 명시적인 요청 시 별도로 기록한다.
