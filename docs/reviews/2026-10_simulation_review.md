# 시뮬레이션 기록 및 표시 검토

작성일: 2026-10-10 (Asia/Seoul)

## 목적과 근거

결과 저장과 그래프 표시 구조를 검토하고 확인한 사실과 미확인 사항을 구분한다. 유도 성능 검증 완료를 의미하지 않는다. 근거는 작업 폴더의 코드 읽기, 사용자가 제공한 MATLAB 출력 및 캡처다. 현재 MATLAB 작업 공간을 직접 읽거나 새 시뮬레이션을 실행하지 않았다.

## 구현 구조

- `main.m`: 동일한 설정으로 각 종류를 독립 실행한다.
- `runSimulation.m`: 상태 적분, 종료 판단, 이력 저장을 수행한다.
- `computePNGuidance.m`: 전달된 종류에 따라 분기를 선택한다.
- `visualizeSimulation.m`: 결과 구조체 배열을 순서대로 표시한다.

## 확인한 사실

속력의 크기는 설정값으로 고정되고 횡가속도 입력에 따라 진행 방향이 변한다. 타겟 운동 입력과 APN 내부 입력은 별도 변수이므로 두 값을 자동으로 연결하는 구조는 아니다.

사용자가 확인한 특정 실행에서 TPN 가속도 기록은 전체 1,024개, 유효값 1,023개, NaN 1개, Inf 0개였다. 같은 실행의 TPN과 APN 가속도 배열에 대한 `isequaln` 결과는 1이었다. 당시 APN 내부 입력은 0이었다. 이 결과는 그 실행에만 해당하며 현재 저장소의 과거 실행에 적용하지 않는다.

동일한 배열을 실선으로 같은 축에 그리면 나중에 그린 선이 앞선 선을 덮을 수 있다. case 분리는 출력값의 차이를 보장하지 않는다. 최대 종료 시각은 공통 설정이지만 실제 마지막 기록 시각은 실행마다 다를 수 있다.

## 기록 및 표시 검토

상태는 적분 후 다음 인덱스에 저장되고 기하·명령은 현재 인덱스에 저장된다. 종료 조건에 도달한 표본에는 명령 NaN이 기록된다. 시간 한도까지 실행한 경우 마지막 기하·명령 행이 실제 계산됐는지 추가 확인이 필요하다. 모든 배열을 일괄적으로 한 칸 줄이는 것은 유효한 데이터를 제거할 수 있다.

각도 표현의 경계, 두 점이 근접한 구간의 기하 민감도, 미기록 표본은 서로 다른 문제다. 캡처의 급변만으로 특정 원인을 확정하지 않는다. 가속도 명령 그래프는 실제 측정 가속도와 구분한다.

## 소스 사본과 한계

작업 폴더와 Git 저장소 `github_upload/`의 main.m 및 src의 7개 MATLAB 파일은 파일 해시가 다르다. 해시 차이는 의미 있는 코드 변경을 증명하지 않으며 줄바꿈 차이도 포함할 수 있다. 이번 반영은 문서만 변경하며 소스를 동기화하지 않는다.

서로 다른 설정의 캡처를 하나의 실험으로 합치지 않는다. 설정과 소스를 복원할 수 없는 그림은 참고 자료로만 취급한다. 추가 확인 대상은 실제 실행 경로, 마지막 표본 값, 기록 시점 및 소스 사본의 내용 차이다.
